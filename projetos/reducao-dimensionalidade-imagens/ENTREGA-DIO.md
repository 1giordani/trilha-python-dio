Pasta do projeto: https://github.com/1giordani/trilha-python-dio/tree/main/projetos/reducao-dimensionalidade-imagens

## Descrição para copiar

Implementação em Python para converter imagens coloridas em níveis de cinza de 0 a 255 e imagens binárias com valores 0 e 255. O projeto utiliza cálculo explícito por pixel, limiar configurável, preservação das dimensões e geração de comparação visual. Inclui notebook para Colab, exemplos executados, testes automatizados e documentação dos resultados.
