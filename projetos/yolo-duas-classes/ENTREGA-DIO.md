# Entrega na DIO

Repositório: https://github.com/1giordani/trilha-python-dio

Projeto: https://github.com/1giordani/trilha-python-dio/tree/main/projetos/yolo-duas-classes

## Descrição para copiar

Projeto de detecção com YOLOv3-tiny/Darknet e Transfer Learning, ampliando a configuração das 80 classes COCO para incluir duas classes novas: marcador triangular e marcador quadrado. Inclui base sintética rotulada automaticamente, conversor de anotações LabelMe XML/JSON para YOLO, transplante dos pesos pré-treinados, notebook para Colab, treinamento piloto executado localmente e avaliação das duas classes novas em dados reservados.

As evidências distinguem o piloto sintético de um treinamento com fotos reais. Não houve rotulagem manual na interface LabelMe nem execução no Colab durante a preparação. Leia as limitações e assista às aulas antes de declarar essas etapas concluídas.
