## Descrição para copiar

Implementação em Python das métricas acurácia, sensibilidade (recall), especificidade, precisão e F1-score a partir de uma matriz de confusão binária. O projeto apresenta fórmulas, interpretação dos resultados, tratamento de divisão por zero, testes automatizados e notebook para Colab, com cálculos explícitos sem bibliotecas prontas de métricas.
