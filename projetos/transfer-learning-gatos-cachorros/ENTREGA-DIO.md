## Descrição

Projeto de Transfer Learning em Python com TensorFlow/Keras e notebook para Google Colab. Utiliza a MobileNetV2 pré-treinada no ImageNet para classificação de gatos e cachorros, com extração de características, fine-tuning, separação de treino/validação/teste e avaliação por métricas e matriz de confusão. Inclui exportação do modelo e documentação das decisões técnicas e das evidências executadas.

Antes de declarar a atividade integralmente concluída, assista às aulas exigidas pela plataforma e confira no README das evidências o escopo do treinamento executado. O notebook padrão pode ser executado no Colab para gerar suas próprias saídas completas.
