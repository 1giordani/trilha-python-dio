## Descrição para copiar

Assistente virtual em Python com SpeechRecognition para fala em português e gTTS para respostas em áudio. Utiliza regras de PLN para abrir pesquisas na Wikipédia e no YouTube, buscar farmácias no Google Maps e informar o horário. Inclui modo de texto, entrada por arquivo de áudio, notebook Colab, tratamento de falhas e 15 testes automatizados. O README documenta instalação, comandos, privacidade e o escopo das validações, incluindo a limitação de conexão no teste de voz.

## Antes de concluir

Execute a assistente no seu computador para validar microfone e reprodução. Assista às aulas e confira os critérios da plataforma. A publicação do código não envia automaticamente a atividade: cole o link no botão Entregar Projeto da DIO.
